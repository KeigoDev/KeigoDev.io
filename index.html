Bank branch deposit analysis, 2010–2016

Financial performance · Python

Analysed seven years of branch deposits to find trends, geographic concentration and branch-level growth opportunities.

Python · Pandas · Matplotlib · Jupyter

Repository ↗ Dataset ↗

How I did it
  • Prepared the data: converted dates, handled missing values, validated deposit columns and removed duplicates.
  • Created Branch Age, Years Since Acquisition, Total Deposits, Growth % and CAGR metrics to compare performance.
  • Analysed yearly trends, top and declining branches, and contributions by state and city.
