AML transaction monitoring in SQL

Financial crime · SQL, Tableau

Fraud caught from 0.2% to 99.5%

Six explainable fraud rules in SQL on 6.3 million PaySim mobile-money transactions. The operator’s own flag caught 16 of 8,197 fraud cases; the combined risk score catches 8,154.

SQL · SQLite · MySQL · Python · Tableau

Open dashboard ↗ Repository ↗ Dataset ↗

How I did it
  • Loaded the 470 MB CSV into SQLite with Python in 500,000-row chunks, keeping each row’s line number so any alert traces back to the file.
  • Cleaned it in SQL: every removed row is logged with its reason, and a check confirms raw = clean + removed. Balance mismatches are kept as a signal, not deleted.
  • Wrote six weighted rules, from account drain and transfer-then-cash-out to mule fan-in. None of them uses the fraud label, and every alert shows which rules it hit.
  • Measured precision and recall for the old flag, each rule and the combined score. Transfer-then-cash-out alone catches 99.5% of fraud at 90% precision.
  • Built a Tableau workbook on the SQL output: KPI tiles, fraud by day and hour, recall by rule, a data quality panel and the alert queue. The same SQL also runs on MySQL 8.

Food affordability in the Philippines, 2026

Economics · Power BI, Python

Rice inflation from −17% to +20% in a year

A Power BI data story on official PSA, ECB, SWS and DOLE data: which regions the 2026 rice price shock hits hardest, and where relief should go first.

Python · Power Query · DAX · Power BI

Open dashboard ↗ Repository ↗ Power BI project ↓

How I did it
  • Pulled rice prices, inflation, GDP and exchange rates from the PSA OpenSTAT and ECB APIs into Excel with Python.
  • Cleaned it in Power Query: unpivoted month columns, turned unreleased-month placeholders into nulls and matched PSA's two region-naming styles.
  • Modelled a star schema with Calendar and Region tables and wrote 46 DAX measures, including latest against a year earlier.
  • Checked every layer with a Python script before sharing: queries, columns, measures and expected card values all agree.
  • Found that 12 of 18 regions have rice inflation above the national 20.3%, led by Western Visayas at 30.0%.
